## Summary

- Worked assigned issue #804: the hook metadata table listed `executionMetadata.handlerOutput` as available only on `onSuccess`/`onComplete`, implying usage can't be recovered in `onError` after a parser failure.
- Verified against source: `handlerOutput` is recorded in `BaseExecutor.execute` (`src/executor/_base.ts:186`) *before* `getHandlerOutput()`, which is where `LlmExecutor` parses. - Added three regression tests so the documented behavior can't silently drift — including the handler-failure case that makes the docs' optional chaining load-bearing.
- Compiled both doc examples against real types in a scratch file.
