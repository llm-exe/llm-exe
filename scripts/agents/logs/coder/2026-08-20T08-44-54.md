## Summary

- Fixed #732: `useLlm("xai.grok-4.20-reasoning", { effort: "high" })` silently dropped `effort`, because `isReasoningModel` in `src/llm/config/x/index.ts` only matched the literal strings `grok-4.3` / `grok-4.5`, while the shorthand resolves to `grok-4.20-0309-reasoning`. - Corrected `xai.test.ts`, which had locked in the bug by listing `grok-4.20-0309-reasoning` under "drops effort for non-reasoning xAI models"; added pass-through and invalid-value cases for that model.
