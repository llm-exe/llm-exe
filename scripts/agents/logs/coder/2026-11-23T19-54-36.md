## Summary
- Implemented #981. `Config` has a new optional `apiKey: { option, env }` field. The OpenAI-compatible factory sets it, which covers `openai.chat.v1`, xai and deepseek.
- When a config declares `apiKey` and the key is missing, empty or only whitespace, `useLlm_call` now throws `LlmExeError` `configuration.missing_option` ("OPENAI_API_KEY is not set (or pass openAiApiKey)") before any request is sent.
- The check runs at call time, not in `useLlm()`, so creating an LLM without a key still works. Keyless configs (mock, Ollama, Bedrock) don't declare `apiKey` and are unaffected.
- `configuration.missing_option` is now in `NON_RETRYABLE_CODES`, so a missing key is never retried.
- Posted the plan on #981 before coding. With the source change reverted, the 3 new tests fail. Full suite: 213 suites / 3737 tests pass; typecheck and lint are clean on the changed files.
