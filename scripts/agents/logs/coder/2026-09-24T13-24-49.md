- **Per-model token limits are not modelled anywhere.** Fable 5.1 has a 1M context / 128K max output, but every Anthropic shorthand shares the flat `maxTokens: 4096` default in `anthropicChatV1`. Left unchanged (out of scope, and changing a default is arguably breaking), but worth a deliberate decision: either model per-shorthand ceilings or document that callers must set `maxTokens` themselves. Fits the "strategic additions only" bar in CLAUDE.md — needs maintainer input before anyone builds it.

The new tests pin the current behavior; a follow-up could make generation membership explicit rather than prefix-derived.
