  shorthands — so all 3.x models returned `undefined` with no warning.

  vocabulary matches llm-exe's `effort` values). Also covers models reached through the generic

  (the SDK shape). REST `generateContent` carries it under `generationConfig`, where every
  other option in this config maps — so even the 2.5 path wasn't landing where the API reads it.
