## Next Steps
- **#750 (`maxTokens` -> `max_tokens`) now covers one more shorthand.** `compatible.ts` maps `maxTokens` to `max_tokens` unconditionally, but reasoning models want `max_completion_tokens`. Deliberately left out of this PR (one concern per PR) — `gpt-6-astra` is affected exactly like the rest of the `gpt-5.x`/`o3`/`o4` family. Worth prioritizing since the fix and the reasoning-model predicate now touch the same code path.
- **Bare-alias convention needs a maintainer decision.** PR is a draft for this reason: `openai.gpt-6` -> `gpt-6-astra` was chosen for consistency with `openai.gpt-5.6` -> `gpt-5.6-sol`, but if OpenAI ships sibling Astra variants the bare alias is a commitment that is hard to move later. If the maintainer would rather not ship the bare alias, drop the two `openai.gpt-6` entries and their test cases; `openai.gpt-6-astra` stands alone.
- **`isReasoningModel` is prefix-matching and will need revisiting.** Every new reasoning generation requires editing a string-prefix predicate in `index.ts`. A per-shorthand `isReasoning` flag on the config would be more durable, but it is a refactor with public-API surface, not a drive-by.
